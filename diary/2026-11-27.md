## 2026-11-27: CC_DIARY_DECISION: the localization rule loaded on code and templates

- Made by hh-advise-hh-rules while supervising, on the push-down audit's A4,
  with the operator's words "I agree with your recommendations."
- Options considered: keep the rule's patterns on the language files and their
  test; add the module's code and templates.
- Chosen: add `hh-coc7-group-check/**/*.js` and `static/templates/*.hbs`,
  because a user-facing string is written in code or a template, often before
  any language file is read, and `tests/lang.test.js` compares the language
  files with `en.json` only, so a string written straight into code is caught by
  nothing. It adds nothing to what loads at the start.
- Rejected: keeping the patterns, because the rule would miss the work that
  needs it first.
- Commits: the commit that adds this entry
- Changes: 2026-11-19, file-tied passages in path-scoped rules
